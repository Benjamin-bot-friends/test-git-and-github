โปรแกรมบันทึกรายรับ-รายจ่าย  
โปรแกรมบันทึกรายรับรายจ่าย ผ่าน terminal commanline พัฒนาด้วย python  
ช่วยให้บันทึกข้อมูลรายรับ หรือรายจ่ายได้อย่างง่ายดาย สามารถคำนวนรายได้รวมสุทธิ รายจ่าย และรายได้ในเวลาเดียวกันในแต่ละเดือน สามารถเรียกดูบันทึกว่ามีรายการไหนในการใช้จ่ายได้

ฟีเจอร์หลัก
- บันทึกรายการซ์้อได้ ใส่รายการที่ซื้อ และจำนวนเงินได้ 
- บันทึกรายการรับได้ ใส่รายการรับ และจำนวนเงิน
  คำนวนยอดรายรับ และ รายจ่าย และ ยอดคงเหลือได้ในแต่ละเดือน
- สามารถดูรายการได้ว่าเคยบันทึกอะไรไปบ้าง
- จัดเก็บข้อมูลอย่างถาวรในรูปแบบไฟล์ `cashbook.json`
- ใช้งานง่ายผ่านคีย์บอร์ดบนหน้าจอ Terminal โดยตรง

### สิ่งที่ต้องมี (Prerequisites)
- Python 3.x ขึ้นไป

### วิธีรันโปรแกรม
1. โคลนโปรเจกต์นี้ลงมาที่เครื่อง หรือเปิดโฟลเดอร์โปรเจกต์ใน VS Code
2. เปิด PowerShell หรือ Terminal
3. ใช้คำสั่ง python real_examDIY.py
