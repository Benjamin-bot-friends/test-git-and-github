### โปรแกรมบันทึกและจัดการข้อมูลทางการเงิน
ซอฟต์แวร์จัดการการเงินส่วนบุคคลที่ทำงานผ่านระบบ Terminal ถูกพัฒนาขึ้นด้วยภาษา Python ใช้ในการบันทึกข้อมูลรายรับและรายจ่าย ระบบมีความสามารถในการประมวลผลข้อมูลแบบภาพรวมรายเดือน ทั้งการสรุปยอดรายได้ ยอดค่าใช้จ่าย และยอดเงินสุทธิคงเหลือตลอดจนมีฟังก์ชันสำหรับเรียกตรวจสอบรายละเอียดของรายการธุรกรรมย้อนหลังได้อย่างครบถ้วนและแม่นยำ  

### ฟีเจอร์หลัก
- บันทึกรายการซื้อได้ ใส่รายการที่ซื้อ และจำนวนเงินได้ 
- บันทึกรายการรับได้ ใส่รายการรับ และจำนวนเงิน
- คำนวณยอดรายรับ และ รายจ่าย และ ยอดคงเหลือได้ในแต่ละเดือน
- สามารถดูรายการได้ว่าเคยบันทึกอะไรไปบ้าง
- จัดเก็บข้อมูลอย่างถาวรในรูปแบบไฟล์ `cashbook.json`
- ใช้งานง่ายผ่านคีย์บอร์ดบนหน้าจอ terminal โดยตรง

### สิ่งที่ต้องมี (Prerequisites)
- Python 3.13.8 

### วิธีรันโปรแกรม
1. โคลนโปรเจกต์นี้ลงมาที่เครื่อง หรือเปิดโฟลเดอร์โปรเจกต์ใน VS Code
2. เปิด PowerShell หรือ Terminal ก่อนจะใช้คำสั่ง ให้ terminal อยู่ใน folder ที่มีไฟล์ " real_examDIY.py "อยู่ หากสร้าง folder และสร้างไฟล์ real_examDIY.py อยู่ด้านในให้ ทำการ cd ตามด้วยชื่อ folder เข้าไปก่อนถึงจะใช้คำสั่งได้ 
3. ใช้คำสั่ง 
```bash
cd foldername # if your terminal are not in the folder
python real_examDIY.py
```
